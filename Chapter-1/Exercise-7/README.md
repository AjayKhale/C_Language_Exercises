# Exercise-7
Write a program to print the value of EOF.
## Compiling Code

To compile code, run the following command

```bash
  gcc main.c -o main >log.out 2>log_error.out
```

## Running Tests

To run tests, run the following command

```bash
  ./main.exe >log.out 2>log_error.out
```

## Output
```bash
EOF = -1
```
